# Fast path: what's different in C++

- **clang-format** (`.clang-format`, YAML; `BasedOnStyle: LLVM|Google|Chromium|Mozilla|WebKit|Microsoft|GNU` plus overrides) formats code deterministically. Check it in CI with `clang-format --dry-run -Werror`; apply it with `-i` or `git clang-format`; protect hand-formatted blocks with `// clang-format off/on`; `SortIncludes` orders includes. Run it on save and in a pre-commit hook so that layout never appears in a review.
- **CMake** is a build-system *generator* (Ninja, Make, MSBuild, Xcode). Out-of-source: `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release`, `cmake --build build`, `ctest --test-dir build`. **Targets and properties, not variables**: `add_library/add_executable`, `target_include_directories`, `target_compile_features(t PUBLIC cxx_std_20)` (or `CMAKE_CXX_STANDARD`), `target_compile_options`, `target_compile_definitions`, `target_link_libraries(t PRIVATE|PUBLIC|INTERFACE ...)`. `PUBLIC` = needed by me and my users; `INTERFACE` = only my users.
- **Avoid**: global `include_directories`/`link_libraries`/`add_definitions`/`CMAKE_CXX_FLAGS`, `file(GLOB)` for sources, in-source builds, unpinned `FetchContent`.
- **Tests**: `enable_testing()`, `include(GoogleTest)`, `gtest_discover_tests(target)` (or Catch2's `catch_discover_tests`), `ctest -R`, `-j`, `--output-on-failure`, `--repeat until-fail:N`.
- **Dependencies**: `find_package(Pkg REQUIRED)` (system or package manager), `FetchContent` (source at configure time), **vcpkg** or **Conan** as package managers (toolchain file / generators), git submodules, or the system's package manager. There is no single standard: follow what your project does.
- **Developer experience**: `CMAKE_EXPORT_COMPILE_COMMANDS ON` (clangd, clang-tidy, cppcheck), `CMakePresets.json` (named configure/build/test configurations shared by humans and CI), `ccache`/`sccache`, Ninja, `CMAKE_CXX_CLANG_TIDY` to run tidy during the build.
- **CI recipe**: format check, build with warnings as errors, unit tests with ASan/UBSan, static analysis, optionally TSan and a coverage report; matrix over compilers (GCC, Clang, MSVC) and build types.
